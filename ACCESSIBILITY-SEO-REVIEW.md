# Проверка по первому кодексу - 19 октября 2026

Проект: Desktop/Portfolio_UX_Oksana. Основа: первый, нерасширенный PDF правил кода.
Изменения внесены локально. Commit, push и публикация не выполнялись.

## Что изменено

- Все четыре страницы: уточнены alt после визуального просмотра изображений. Декоративные иконки, повторяющие соседние подписи, имеют пустой alt; декоративные стрелки исключены из озвучивания.
- На главной существующая фраза «Hi, my name is Oksana» стала H1 с прежним размером, начертанием и отступами. Названия проектов стали H2; подзаголовки с типом проекта стали абзацами с прежними классами. Текст бренда в шапке перестал быть заголовком и сохраняет исходный вид.
- Добавлены имя основной навигации, переход к main и видимый фокус. Ссылка перехода появляется только при клавиатурном фокусе.
- Повторяющиеся ссылки Learn More, Figma, Live App и ссылки на рекомендателей имеют уточняющий контекст в доступном имени. Видимые надписи и адреса сохранены. Для новых вкладок добавлены предупреждение и недостающий rel.
- Прокручиваемые макеты доступны с клавиатуры и имеют разные названия регионов.
- У изображений заданы собственные width/height, чтобы браузер мог резервировать место до загрузки. Изображения не заменялись и не перекодировались.
- При prefers-reduced-motion видео не запускается автоматически, а плавная прокрутка отключается. Существующие нативные controls видео и обычный вид сохранены.
- Декоративный логотип выполняет один четырёхсекундный цикл вместо бесконечного движения; дополнительная видимая кнопка не добавлялась.
- В начало общей styles.css добавлен :root с повторяемыми цветами, шрифтами и шириной container. Исходные значения сохранены. Правила остаются централизованными; удалён один явно перекрытый justify-content.
- Текст ссылок шапки и hero при наведении использует более тёмный существующий фиолетовый #6759b2. Причина: исходный цвет #b47cff в шапке давал около 2,89:1 на белом; #6759b2 даёт около 5,76:1. Базовые цвета, изображения, размеры и композиция сохранены.

## SEO

- У всех четырёх страниц собственный canonical с полным адресом GitHub Pages.
- Добавлены недостающие description и социальные метаданные кейсов; заголовок Muslim Platform уточнён до Online Platform for Muslim Women | Oksana Pleshkan.
- Добавлены описания социального превью и данные Person без новых биографических утверждений.
- Создан sitemap.xml с главной и тремя кейсами. Lastmod соответствует текущей правке исходников.
- Создан robots.txt с явным комментарием о GitHub Pages: файл в /Portfolio_UX_Oksana/ не является действующим robots.txt для всего хоста. Поисковики используют https://oksana-pl.github.io/robots.txt. Этот проектный файл не изменяет правила обхода хоста и может служить шаблоном при другом размещении.
- После публикации sitemap можно передать в подходящий ресурс Google Search Console. Индексация, выбранные Google canonical, показы, позиции и лиды без доступа к аккаунту не подтверждены.

## Проверки

- Сравнены исходная и исправленная версии четырёх страниц при 1440 и 390 px после прокрутки и загрузки всех изображений. Размеры и позиции проверенных секций совпали во всех восьми случаях. Это проверка браузером, а не визуальное принятие пользователем.
- Горизонтальное переполнение не обнаружено; все используемые изображения загрузились.
- Проверены клавиатурный переход к main, фокус и прокрутка длинного макета Design System. Просмотрено дерево доступности браузера.
- Пройдены изолированные тесты начальной настройки reduced motion и её переключения, с видео и без него, включая отсутствие IntersectionObserver. Пройден node --check.
- Проверены сохранение видимого текста, один H1 на страницу, уникальность ID, наличие alt, локальные ресурсы, JSON-LD, sitemap и git diff --check.
- HTML, CSS и JavaScript оставлены в существующем проекте без новых библиотек и массового переформатирования.

## Границы проверки

- Полное прослушивание VoiceOver/NVDA, аудит всех применимых критериев WCAG и сертификация соответствия не выполнялись. Дерево доступности не заменяет настоящий скринридер.
- Для видео не заявляется проверка всех аудио- и видеотреков, субтитров или аудиоописания; их необходимость требует отдельной содержательной проверки. Существующие описания кейса и нативные элементы управления сохранены.
- Полная транскрипция каждого текста внутри длинных скриншотов и диаграмм не добавлялась. Alt объясняет изображение; соседний текст даёт контекст. При необходимости подробного изучения всех деталей потребуется отдельная доступная текстовая версия.
- Форм отправки в этом проекте нет; новые формы и сервисы не добавлялись, внешние сообщения не отправлялись.
- Реальные данные Core Web Vitals, Search Console, доставка email, сторонние Figma/Drive-права и все внешние сервисы не проверены.
- Резервная копия исходных HTML/CSS/JS находится в /tmp/ux-accessibility-before. Изображения и icons в ней подключены ссылками; сами оригинальные медиа не изменялись. Каталог /tmp временный; для долгосрочного хранения используйте Git.
