Case Studies

Climate Finance App

A work placement project developed for Trócaire

Working with Trócaire, an International Non-Governmental Organisation, I developed an early educational idea into a working digital tool for facilitated school workshops. The aim was to help young people explore how real climate finance negotiations work.

My work covered research, game mechanics, user flows, interface design, prototyping, testing and iteration.

Online Platform for Muslim Women

University project

A social platform designed for Muslim women with gender verification at registration. The platform allows users to share content, run blogs, and sell services or products in a women-only environment. I conducted user research and designed an interactive prototype in Figma.

Minimal E-commerce Design System

University project

I created a reusable design system for e-commerce interfaces to improve UI consistency, speed up the design process, and support scalable product development across desktop and mobile platforms.

Alongside the Figma design system, I built an HTML and CSS component library with reusable styles, selected UI components, and code examples.

Accessible Zoo Navigation

Final Year Project (In Progress)

I’m exploring how people who are blind or have low vision can visit a zoo independently and safely while getting the most out of the experience. My research focuses on the barriers they face and how a digital navigation tool could help them explore, learn and enjoy their visit.

The project is currently in the research stage, with a first working prototype and user testing planned for March 2027.
